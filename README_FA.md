# VPN Pay Android — نسخه حرفه‌ای

این مخزن یک پروژه کامل اندروید برای ساخت APK از طریق GitHub Actions است. برای Build به Android Studio نیاز ندارید.

## قابلیت‌ها
- رابط کاربری فارسی و راست‌چین‌پذیر با تنظیمات قابل تغییر
- تنظیم آدرس endpoint سرور، کلید `X-Secret` و فهرست فرستنده‌های مجاز
- فعال/غیرفعال کردن ارسال پیامک
- درخواست مجوز RECEIVE_SMS از داخل برنامه
- ارسال فقط پیامک فرستنده‌هایی که دقیقاً در فهرست مجاز ثبت شده‌اند
- استفاده اجباری از HTTPS
- عدم ثبت متن پیامک در Log
- تلاش مجدد تا ۵ مرتبه در صورت خطای ارتباط

## ساخت APK با GitHub Actions
1. تمام محتویات این پوشه را در ریشه یک GitHub repository آپلود کنید.
2. به تب **Actions** بروید.
3. Workflow با نام **Build VPN Pay APK** را انتخاب کنید.
4. روی **Run workflow** بزنید.
5. پس از موفقیت، در پایین صفحه اجرای Workflow بخش **Artifacts**، فایل `VPN-Pay-debug-APK` را دانلود کنید.
6. ZIP دانلودشده را باز کنید؛ فایل `app-debug.apk` داخل آن است.

با هر Push به شاخه `main` نیز Build خودکار اجرا می‌شود.

## تنظیم برنامه
پس از نصب و باز کردن برنامه:
- **Server URL:** آدرس کامل endpoint دریافت پیامک، مانند `https://pay.example.com/sms`
- **SMS Secret:** همان مقدار `SMS_SECRET` در سرور
- **فرستنده‌های مجاز:** نام یا شماره فرستنده پیامک بانک، دقیقاً مطابق پیامک؛ چند مورد با کاما جدا شوند.
- ارسال را فعال و تنظیمات را ذخیره کنید.
- مجوز دریافت پیامک را اعطا کنید.

## سازگاری با سرور موجود
این برنامه JSON با دو فیلد `sender` و `body` را به endpoint تنظیم‌شده POST می‌کند و هدر `X-Secret` می‌فرستد؛ بنابراین با endpoint `/sms` سرور موجود در فایل ZIP اولیه سازگار است، به شرط اینکه `SMS_SECRET` و `ALLOWED_SENDERS` سرور نیز درست تنظیم شده باشند.

## نکات مهم امنیتی و عملیاتی
- پیامک بانکی به‌تنهایی اثبات رمزنگاری‌شده و مستقلِ واریز نیست؛ این روش بر اعتماد به پیامک دریافتی گوشی تکیه دارد. برای مبالغ مهم، کنترل دستی/منبع بانکی معتبر و مانیتورینگ لازم است.
- نصب APK با مجوز SMS نیازمند اعتماد کامل به کد و سرور مقصد است. برنامه را فقط روی گوشی تحت کنترل خودتان نصب کنید.
- این پروژه برای توزیع از Google Play طراحی نشده؛ سیاست‌های Google Play درباره مجوزهای SMS محدودکننده است.
- کلید داخل تنظیمات برنامه روی دستگاه ذخیره می‌شود. از کلید مجزا و قابل تعویض استفاده کنید و در صورت افشا آن را عوض کنید.
- برای جلوگیری از ارسال ناخواسته، فقط فرستنده‌های دقیق و شناخته‌شده بانک را وارد کنید.
- اگر گوشی خاموش یا بدون اینترنت باشد، این نسخه صف دائمی آفلاین ندارد؛ پس از پایان تلاش‌ها، ارسال ناموفق می‌ماند.
- برای کارکرد بهتر، محدودیت باتری برنامه را در تنظیمات گوشی روی حالت بدون محدودیت قرار دهید.
- این نسخه متن پیامک را فقط به سرور تنظیم‌شده می‌فرستد و آن را در Log برنامه ثبت نمی‌کند.
